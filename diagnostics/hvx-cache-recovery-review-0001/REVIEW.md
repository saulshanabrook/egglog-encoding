## Safety gate discovered during review

**Do not launch the proposed longer canary yet.** `lib/utils/DSLInstructionUtils.py117` uses `Popen(start_new_session=True)` for Racket, and locally sends `killpg` to that new group on its180-second timeout (lines119–124). `benchmarking/memory_guard.py73–81` samples only the root PGID; `benchmarking/pilot.py` cleans only that group. Detached Racket and solver descendants are therefore excluded from the recorded group RSS and may outlive outer cleanup. The measured4.795 GiB peak is **root-group only**, not total native-source usage. Host-pressure checks still ran; they do not repair per-workload accounting or cleanup. Removing `start_new_session` alone is unsafe because the source's local `killpg` would then target the outer parent group.

## Recommendation (after the separate guard gate)

Make one fresh, complete HVX blur3x3 parent attempt with an explicitly recorded **3,600-second source acquisition cap**, unchanged 5 GiB process-group ceiling, 10 GiB disk reserve, host-pressure guard and stop-on-safety-failure behavior. Preserve the original empty-cache start and every cold/raw/abstract transition. The longer interval is a bounded diagnostic budget, **not a predicted completion time**; current evidence cannot bound all remaining Halide abstraction, subsequent HVX abstraction, later source children or final code generation. Do not automatically retry after another timeout or memory stop.

The narrow implementation would add optional `source_timeout_sec` to each MISAAL request, defaulting to the existing 900 seconds. Validate an actual positive integer (reject booleans, zero, negatives, floats and nonnumeric strings) in [verified_request](/Users/saul/p/egglog-encoding/scripts/misaal_reproduction.py:44), then pass it at the existing guarded [capture_misaal call](/Users/saul/p/egglog-encoding/scripts/misaal_reproduction.py:742), replacing only the current hardcoded `timeout_sec=900` at line746. An explicit policy upper bound, e.g.3,600 seconds for this diagnostic, is appropriate. Keep ordinary replay's separate 300-second settings unchanged. Record the effective source cap in the capture/process metadata for both default and override cases. Create a new request/settings artifact and immutable attempt; do not rewrite the failed request or attempt.

The coordinator already hashes the selected complete request file before reuse ([case_identity](/Users/saul/p/egglog-encoding/scripts/suite_reproduction.py:64)) and the acquisition implementation ([family dependency list](/Users/saul/p/egglog-encoding/scripts/suite_reproduction.py:88)); the selected request also verifies the actual case/source/configuration ([misaal_request](/Users/saul/p/egglog-encoding/scripts/reproduction_dispatch.py:14)). ## Why an ordinary shared warm cache is not faithful

[Halide.py](/Users/saul/p/egglog-encoding/benchmarks/local/reproduction/prerequisites/misaal-44ff/attempt-20260925T051740Z-ef4010cc/sources/MISAAL/lib/patterns/Halide.py:43) and [HVX.py](/Users/saul/p/egglog-encoding/benchmarks/local/reproduction/prerequisites/misaal-44ff/attempt-20260925T051740Z-ef4010cc/sources/MISAAL/lib/patterns/HVX.py:59) implement three distinct branches:

1. **Cold:** generate/prune/deduplicate raw patterns, save the raw pickle, and use those patterns in the current source child.
2. **Raw cache exists:** load raw patterns, run the real abstractor and its helper validators, then save the abstracted result. The exported `Halide_patterns`/`HVX_patterns` variable is **not assigned the returned abstract list in this branch**.
3. **Abstract cache exists:** load the abstract list for later source children.

Moreover the raw-to-abstract branch mutates loaded objects while bucketing: [PatternUtils.py515](/Users/saul/p/egglog-encoding/benchmarks/local/reproduction/prerequisites/misaal-44ff/attempt-20260925T051740Z-ef4010cc/sources/MISAAL/lib/patterns/PatternUtils.py:515) swaps pattern direction, and canonicalization is also invoked during abstraction. Hence replacing the second child's list with either untouched raw data or final abstract data is not justified. The unchanged generated child imports Halide first and HVX second, then concatenates those lists for the compiler. The observed second child had not reached HVX abstraction when stopped.

The current preparation contract expressly requires a fresh empty attempt-owned directory ([preparer](/Users/saul/p/egglog-encoding/scripts/reproduction_prepare_misaal.py:611)); [run_frontend](/Users/saul/p/egglog-encoding/scripts/misaal_reproduction.py:595) creates it and all source children share only that attempt's state. Prewarming changes which rules the first child receives. Copying retained raw caches from the failed attempt likewise changes the first child from cold to abstraction. Relabeling an incomplete helper prefix as a cache is impermissible. None is a drop-in recovery under the existing contract.

## If shared preparation is pursued later

A separate reviewed transition-aware contract would be necessary. It must retain original ordered pattern inputs/DSL/source/loaded-class identities, Python and pickle runtime, helper backend and actual Boolean results, exact reviewed deduplication version, per-branch cache input/output bytes, and the effective pattern objects consumed by every source child—including in-place mutations in the raw branch. Thread-completion order can affect abstract-list ordering; freezing and identifying the actual produced bytes is required rather than assuming deterministic re-generation.

Native `PatternUtils.py616–622` also discards submitted Futures and waits without calling their results. An abstract pickle can therefore exist without independently establishing that every worker completed without an exception; a future preparation contract must explicitly account for every bucket/helper outcome. The current helper observer catches its observed subprocess failures, but is not a general audit of every Python abstraction operation. Helper acceptance also establishes backend execution/type/saturation/extraction acceptance, not an independent semantic-equivalence proof.

The safest reusable unit is an immutable **completed preparation/evidence artifact**, not a mutable directory shared by active benchmarks. But substituting such an artifact into this exact cold-parent workload would still need a justified mechanism preserving its cold/raw/abstract sequence and graph-changing pattern contents. Replacing the source's abstraction with a cached side effect is an additional behavioral adaptation, not accomplished by pointing an environment variable at a warm folder. Require direct comparison of emitted complete Egglog programs/rules/schedules/costs/outputs across the original and prepared paths before admission. No implementation of that larger contract is proposed here.
