The collector keeps the empty/configured evidence root out of immutable pre-run artifacts; it archives each captured output tree separately after terminal status, binding its actual child/index in the row. This avoids hashing a mutable directory as a source artifact. The existing frozen collector requires no general argv-template facility; an extra optional run-data locator can be handled with its existing output receipt contract after the harness owner checks compatibility. Direct `build_program` tests may continue to use a caller-supplied fresh directory, or receive the allocated path explicitly if review favors that clearer API; do not allocate separately for every pass.

Manual/Injective use the same output protocol; this is a total checker-package cost, not a pure cancellation cost. Existing phase/component limits still apply.
