# A1 actual compiler integration attempt

The bounded attempt fails conservative import admission. It establishes no new compiler bug or speedup. It is terminal within the prescribed initial implementation plus one functional revision budget; it does not refute the NoAlias law or prove that a further bounded implementation is impossible.

The fresh copies are `/private/tmp/eggcc-alias-actual` and `/private/tmp/encoding-alias-actual`. All compiler changes are confined to those copies. The immutable source input, prior design, prior installation receipts and retained graph were copied and hashed before tests. `admission.json`, `revision-1.json`, `source-identities.json` and `final-source-r1.tar` bind initial/final sources. `bin/eggcc` is the actual rebuilt compiler; `binary-identities.json` records its hash. The existing U0 compiler and runtime remain unchanged.

The initial five A1 tests registered and ran: four passed, while the positive retained-graph certificate failed because it expected allocation type `IntT` instead of current `PointerT(IntT)`. The private generic causal controls, finite Manual stage/rescue tests, guard rejection test and one-shot action parity against the actual existing commute/store-forward rules passed.

The one functional revision fixes the allocation type, links private symbols and source seed to the current certificate, executes primitive metadata comparisons, adds exact inner-If true-branch ancestry, and tightens function/context/effect checks. It compiles, but the conservative Expr-valued-row whitelist rejects the admitted auxiliary `TupleRemoveAt` and `to-hoist` rows. Six focused tests ran: three passed and three failed before a positive certificate. The complete host library suite ran 70 tests: 67 passed and the same three new A1 tests failed. These failures are retained and not waived. No additional functional revision was made.

The actual compiler matrix nevertheless ran all 18 positive modes: U0, Off/B1, SeedOnly, SeedOff, PrimitiveOnly, Encoding, Manual, reverse/shift/cell/query knockouts, transport-off, bridge-off, consumer-off, and index/shift/cell/branch rescues. Each interprets the original and optimized program identically and passes 12 native oracle rows, including both index orders, zero/one/eight/1,024/1,000,000 iterations, equal-index and invalid-bound paths. That is 216 native checks. Thirteen additional arms cover different masks, unequal shifts, changed pointer transport and no-context execution; their 17 native checks also pass. All 31 original/result interpreter pairs agree.

Every enabled actual A1 mode rejects before private query/export. Thus the matrix is fail-closed correctness evidence, not successful private reasoning, transport, knockout or rescue causality. `acceptance.json` marks those gates unestablished. The initial standalone rule and generic-chain tests do not substitute for successful actual import.

No endpoint difference exists in this attempted implementation, so no timing samples were collected.
